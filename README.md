# Fisio AI Academy

Plataforma educacional de inteligência artificial aplicada à fisioterapia, pesquisa e gestão.

## MVP

- Next.js + TypeScript + Tailwind CSS
- Painel do aluno e do professor (demonstração)
- Trilha piloto: IA do Zero à Prática (12 semanas)
- Supabase planejado para autenticação e persistência

## Executar

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

> Estado: protótipo inicial. Não utilizar dados reais de alunos ou pacientes antes de implementar autenticação, autorização e políticas de privacidade.

## Custos

Desenvolvimento local gratuito; serviços de nuvem devem permanecer dentro dos limites gratuitos.
